# FARZ Brand Guide (v0.1)

## Brand
- **Name:** FARZ | فَرز
- **Tagline:** صوّر. تعرّف. افرز.
- **Product:** Offline-first Android app that classifies one waste item per image into five material classes.
- **Personality:** Clear, calm, practical, modern, environmentally aware.

## Color tokens
| Token | Hex | Use |
|---|---|---|
| Forest Green | `#176B50` | Primary brand color, light-mode actions |
| Mint Green | `#BCE8D4` | Soft highlights and selected states |
| Eco White | `#F5F7F2` | Light-mode app background |
| Deep Charcoal | `#24332D` | Light-mode text and dark-mode surfaces |
| Amber | `#E6A23C` | Caution and attention states only |
| Soft Sage | `#E6EFE9` | Secondary cards and subtle surfaces |
| Dark Background | `#17251F` | Dark-mode background |
| Dark Surface | `#24332D` | Dark-mode cards |
| Dark Primary | `#8DD4B2` | Dark-mode primary actions and accents |

## Typography
- Arabic: IBM Plex Sans Arabic (preferred); system Arabic fallback during prototype.
- Latin: Inter (preferred); system sans-serif fallback.

## Visual rules
- Prefer simple geometry, generous spacing, and rounded cards.
- Avoid dense dashboards, excessive gradients, and decorative recycling symbols.
- Keep contrast high in both themes.
- Do not encode a class using color alone; always show its name and icon/label.

## Themes
- Light: `#F5F7F2` background, `#176B50` primary, `#24332D` text.
- Dark: `#17251F` background, `#24332D` surface, `#8DD4B2` primary.
- Theme choices: System (default), Light, Dark.

## Logo files
- `app/assets/brand/farz_logo.svg`: horizontal wordmark.
- `app/assets/brand/farz_app_icon.svg`: app icon concept.
- SVGs are editable starting assets; Android launcher assets will be generated during final app integration.
